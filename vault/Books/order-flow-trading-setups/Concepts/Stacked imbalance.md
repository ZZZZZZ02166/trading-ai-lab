# Stacked imbalance

- **A Stack Groups Neighboring Same-Side Imbalances**. Adjacent imbalance levels on the same side form a stack. Dale describes the usual display as three or more, while the trading instructions allow the configured trigger to vary. The stack highlights a band of unusually one-sided execution. [PDF pp. 37–38](../../../../books/Order-Flow-Trading-Setups-1.pdf#page=37)
- **Trade Stacked Imbalance Retests With Directional Context**. A stack during a one-way move defines a candidate band. Dale waits for price to move away before it comes back and uses only the first test in this setup. A buying stack approached from above is considered possible support, and the mirrored case possible resistance. [PDF pp. 65–70](../../../../books/Order-Flow-Trading-Setups-1.pdf#page=65)
- **Reassess a Trail When Order Flow Turns**. Dale trails a favorable position while aggressive execution still supports the move. Opposing imbalance, renewed absorption, or a delta reversal near a significant price can change that read. The decision is conditioned on price location and progress. [PDF pp. 110–114](../../../../books/Order-Flow-Trading-Setups-1.pdf#page=110)
