# Hardware software and feeds

[PDF pp. 61–63](../../../../books/Volume%20Profile%20%26%20Market%20Profile%20Order%20Flow%20for%20Next%20Gen%20Daytrading.pdf#page=61)

Forthmann explains the charting and data setup needed to compare price, depth, and executed order flow. The book's platform and vendor descriptions reflect its publication period. The durable requirements are sufficient intraday granularity, a clear mapping between feed and instrument, and consistent session definitions. Charting complexity is useful only to the extent that it supports the decision sequence.
