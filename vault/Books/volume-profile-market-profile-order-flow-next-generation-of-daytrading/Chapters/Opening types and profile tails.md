# Opening types and profile tails

[PDF pp. 108–117](../../../../books/Volume%20Profile%20%26%20Market%20Profile%20Order%20Flow%20for%20Next%20Gen%20Daytrading.pdf#page=108)

An opening drive is evaluated against prior balance and the path leading into the session. A directional start after consolidation differs from one after a long, crowded extension. The crude and E-mini examples mark a local range, profile tails and a false break. The smaller footprint then tests whether aggressive execution supports the recovery. This is an example of the same tool set being used at more than one horizon.
