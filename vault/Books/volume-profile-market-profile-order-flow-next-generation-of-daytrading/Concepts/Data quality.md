# Data quality

- **Treat Value-Area Traversal Rates as Historical Claims**. The book mentions an older 80 percent rule for traversing prior value and qualifies its use in current markets. A reproducible test needs explicit definitions for the open, the entry back into value, target touch and observation horizon. A quoted historical heuristic is only a hypothesis for the repo. [PDF p. 30](../../../../books/Volume%20Profile%20%26%20Market%20Profile%20Order%20Flow%20for%20Next%20Gen%20Daytrading.pdf#page=30)
- **Stack Settings Depend on Platform and Instrument**. The E-mini illustration compares adjacent price rows and illustrates a two-to-one labeling example. Forthmann also allows interpretation of an imperfect stack when neighboring activity supports it. A runnable test needs to declare the ratio, adjacency, minimum size, and treatment of gaps. [PDF pp. 71–73](../../../../books/Volume%20Profile%20%26%20Market%20Profile%20Order%20Flow%20for%20Next%20Gen%20Daytrading.pdf#page=71)
- **Footprint Magnitudes Depend on the Instrument**. In choosing markets, Forthmann compares pace, session timing, liquidity and usual contract sizes. A large print in a thin contract can look small in a more active contract. Use comparable session windows before interpreting relative activity. [PDF pp. 105–107](../../../../books/Volume%20Profile%20%26%20Market%20Profile%20Order%20Flow%20for%20Next%20Gen%20Daytrading.pdf#page=105)
