# Session context

- **Main-Session Activity Shapes the Intraday Context**. The book distinguishes participants by horizon and purpose, including hedgers, longer-horizon traders, and day traders. Their activity varies by instrument, release schedule, and primary session. Forthmann treats a single participant label as an interpretation of observed behavior. [PDF pp. 14–18](../../../../books/Volume%20Profile%20%26%20Market%20Profile%20Order%20Flow%20for%20Next%20Gen%20Daytrading.pdf#page=14)
- **Initial Balance Anchors Opening Range Extension**. The first opening brackets define an initial balance, often the first two half-hour brackets in the illustration. Trade beyond that range is an extension. Forthmann treats a relatively narrow balance as a reason to watch for expansion, and the active instrument and session matter. [PDF pp. 20–21](../../../../books/Volume%20Profile%20%26%20Market%20Profile%20Order%20Flow%20for%20Next%20Gen%20Daytrading.pdf#page=20)
- **Value Area Contains About Seventy Percent**. Forthmann uses the approximately 70 percent of selected activity bracketed by value area high and value area low. The reference depends on the instrument, interval, and whether the distribution is volume or time based. It provides a way to compare the current open with prior acceptance. [PDF pp. 28–30](../../../../books/Volume%20Profile%20%26%20Market%20Profile%20Order%20Flow%20for%20Next%20Gen%20Daytrading.pdf#page=28)
- **Track Acceptance Versus Reentry at Prior Value**. The location of the open is only the first observation. Forthmann distinguishes an outside open that sustains activity beyond value from one that quickly returns inside. In balance, the prior control price can be an intermediate rotation reference. [PDF pp. 28–30](../../../../books/Volume%20Profile%20%26%20Market%20Profile%20Order%20Flow%20for%20Next%20Gen%20Daytrading.pdf#page=28)
- **Compare Like Sessions Before Comparing Profiles**. Fixed profiles provide consistent daily, weekly or monthly windows. Forthmann checks main-session and 24-hour profiles separately because they can place the highest-volume node at different prices. He emphasizes recent references and uses older levels selectively. [PDF pp. 34–38](../../../../books/Volume%20Profile%20%26%20Market%20Profile%20Order%20Flow%20for%20Next%20Gen%20Daytrading.pdf#page=34)
- **Prepare Active-Session References Before the Opening**. Forthmann reviews the prior main-session high and low, overnight or early-session extrema, recent value and POCs, and the scheduled release calendar. Preparation creates scenarios for the open. The source's timing examples should be interpreted for their specific instrument and session. [PDF pp. 95–100](../../../../books/Volume%20Profile%20%26%20Market%20Profile%20Order%20Flow%20for%20Next%20Gen%20Daytrading.pdf#page=95)
- **Footprint Magnitudes Depend on the Instrument**. In choosing markets, Forthmann compares pace, session timing, liquidity and usual contract sizes. A large print in a thin contract can look small in a more active contract. Use comparable session windows before interpreting relative activity. [PDF pp. 105–107](../../../../books/Volume%20Profile%20%26%20Market%20Profile%20Order%20Flow%20for%20Next%20Gen%20Daytrading.pdf#page=105)
- **An Opening Drive Depends on the Prior Auction**. Forthmann distinguishes directional opening initiative from a test or rotation. An early push following consolidation can carry a different meaning from a push after several already extended sessions. Earlier tails, value and the new auction provide reference points. [PDF pp. 108–112](../../../../books/Volume%20Profile%20%26%20Market%20Profile%20Order%20Flow%20for%20Next%20Gen%20Daytrading.pdf#page=108)
- **Examples Combine Distinct Pieces of Auction Evidence**. FDAX uses a previous VPOC with local delta and footprint evidence, Bund uses a double distribution and later buying sequence, and crude profiles successive intraday legs. Each case applies the same sequence to different market speeds. The examples illustrate the author's process on selected trades. [PDF pp. 137–147](../../../../books/Volume%20Profile%20%26%20Market%20Profile%20Order%20Flow%20for%20Next%20Gen%20Daytrading.pdf#page=137)
- **Track Prior and Overnight Extremes for Sweeps**. The book shows squeezes and prior-day or non-institutional highs and lows getting taken during the main session. The useful observation is how price responds after the extreme is reached, with profile and order flow supplying context. A sweep by itself only identifies the path through the level. [PDF pp. 178–193](../../../../books/Volume%20Profile%20%26%20Market%20Profile%20Order%20Flow%20for%20Next%20Gen%20Daytrading.pdf#page=178)
- **Separate Initial Setup From Multi-Session Holding**. The final EUR/USD example begins with a local backfire setup and then shows the wider hourly path over subsequent sessions. The original evidence and the later holding decision have different horizons. It is an example of how the method scales across views. [PDF pp. 204–207](../../../../books/Volume%20Profile%20%26%20Market%20Profile%20Order%20Flow%20for%20Next%20Gen%20Daytrading.pdf#page=204)
