# Fat Tails: Excess Kurtosis Across Markets (Empirical Table)

**Type:** market_structure_insight
**Source:** Volatility Trading, + Website Wiley (2013) — pp. 55-55

## Summary

Figure 3.7 shows S&P 500 daily returns vs normal distribution — the actual distribution has a higher peak and much fatter tails. Table data for excess kurtosis by market: Hang Seng: 32.7 (extreme); WTI Oil: 3.0; Nasdaq: 9.9; Nikkei: 6.7; FTSE 100: 6.4; IBM: 4.4; Google: 2.0. Normal distribution has excess kurtosis = 0. Values >> 0 mean large moves occur far more often than BSM predicts. Consequence for option sellers: short gamma positions face larger losses than delta-alone estimates suggest. OTM options are systematically underpriced by BSM.
