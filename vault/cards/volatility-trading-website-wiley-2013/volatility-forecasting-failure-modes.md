# Volatility Forecasting Failure Modes

**Type:** caution
**Source:** Volatility Trading, + Website Wiley (2013) — pp. 78-78

## Summary

Common pitfalls in vol forecasting: (1) Lookback bias: the 'best' GARCH parameters are always found with hindsight. Out-of-sample performance degrades significantly. (2) Regime shifts: GARCH trained on calm periods underestimates crisis vol and vice versa. (3) Structural breaks: mergers, leverage changes, index rebalancing alter vol permanently. (4) Fundamental forecasting: earnings growth, analyst dispersion, market cap can predict vol cross-sectionally but add noise when used as timing signals. Best practice: blend multiple forecasts (GARCH + cone + implied + fundamental) and express uncertainty as a range, not a point estimate.
