# Volatility Clustering: Autocorrelation in Squared Returns

**Type:** mechanism
**Source:** Volatility Trading, + Website Wiley (2013) — pp. 53-53

## Summary

Figure 3.1 shows S&P 500 30-day vol from 2000–2011 with visible clustered regimes. Figures 3.2 and 3.3 show autocorrelation for squared returns and absolute returns of S&P 500: both decay slowly and positively across many lags (weeks to months). Absolute returns show stronger autocorrelation than squared returns — this is a robust empirical fact. VIX annualized daily vol = 0.96 (daily changes noisy), weekly = 0.84, monthly = 0.59 (Figure 3.5-3.6) — vol mean-reverts across time scales. GARCH(1,1) was designed specifically to capture this clustering property.
