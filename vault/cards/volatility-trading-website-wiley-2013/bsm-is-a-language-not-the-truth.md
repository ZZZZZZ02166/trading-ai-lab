# BSM Is a Language, Not the Truth

**Type:** principle
**Source:** Volatility Trading, + Website Wiley (2013) — pp. 8-8

## Summary

Sinclair's central framing: the Black-Scholes-Merton model should be treated as a language for communicating about options, not as a true description of reality. Every market participant uses BSM (or a variant) to quote IVs and Greeks, so it serves as a shared coordinate system even when its assumptions are violated. The model's value is not in producing correct theoretical prices — it is in allowing traders to identify relative mispricings and translate positions into risk exposures. Using a wrong model consistently is better than switching models constantly.
