# Five Historical Volatility Estimators Overview

**Type:** concept
**Source:** Volatility Trading, + Website Wiley (2013) — pp. 33-33

## Summary

Sinclair presents five realized volatility estimators, each using different price data: (1) Close-to-Close (CC): σ² = [1/(n-1)] Σ(ln(Cᵢ/Cᵢ₋₁))² — simplest, uses only closing prices; (2) Parkinson: uses daily high/low range — 4.9× more efficient than CC; (3) Garman-Klass: uses open, high, low, close — 7.4× more efficient than CC; (4) Rogers-Satchell: handles drift; uses O,H,L,C; drift-independent; (5) Yang-Zhang: combines overnight gap + intraday range; handles both drift and gaps. No single estimator dominates all situations. Use multiple and compare.
