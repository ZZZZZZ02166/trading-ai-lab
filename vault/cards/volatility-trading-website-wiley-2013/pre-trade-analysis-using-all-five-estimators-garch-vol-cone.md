# Pre-Trade Analysis Using All Five Estimators + GARCH + Vol Cone

**Type:** strategy_idea
**Source:** Volatility Trading, + Website Wiley (2013) — pp. 250-250

## Summary

Sinclair demonstrates on AAPL (June 2007, iPhone launch period). Table 14.2 shows all five estimator readings plus GARCH and high-frequency vol: Yang-Zhang: 33.1%, Close-to-Close: 25.1%, Parkinson: 25.3%, Garman-Klass: 28.2%, GARCH: 36.1%, High-frequency: 44.9%. Figure 14.6 (volatility cone) shows AAPL's 2-year historical cone — current 30-day IV ≈ 41% is near the historical maximum for 30-day horizon. Convergence: most estimators cluster around 25-36%, IV = 41% = overpriced. Figures 14.2–14.5 show each estimator's time series declining since early 2006. Decision: short AAPL implied volatility via straddle. The key lesson: pre-trade analysis requires consensus across multiple forecasting methods.
