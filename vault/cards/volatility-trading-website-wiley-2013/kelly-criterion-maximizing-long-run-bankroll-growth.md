# Kelly Criterion: Maximizing Long-Run Bankroll Growth

**Type:** concept
**Source:** Volatility Trading, + Website Wiley (2013) — pp. 144-144

## Summary

The Kelly criterion (Kelly 1956) specifies the fraction f* of bankroll to bet per trade to maximize long-run wealth. For a binary bet: f* = (p × b − q) / b = p − q/b, where p = win probability, q = 1-p, b = win payoff. Simplified for p = win prob, W = win amount, L = loss amount: f* = p/L − q/W = edge / odds. For options with continuous P/L distribution: maximize E[ln(1 + f × G)], where G is the trade outcome distribution. Figure 8.4 shows expected bankroll as function of bet size: bell-shaped curve peaking at f* ≈ 0.17 for a typical trade. Betting more than Kelly → bankroll depletes (over-bet reduces geometric mean).
