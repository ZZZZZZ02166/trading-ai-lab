# QQQ Variance Premium: Empirical Results Across Strategies

**Type:** market_structure_insight
**Source:** Volatility Trading, + Website Wiley (2013) — pp. 225-225

## Summary

Figures 11.2–11.5 and 11.8 show equity curve results from selling QQQ/QQQQ options (second expiration, various structures, 1996–2012 approximately): 50-Delta straddle: avg weekly return 9.8%, total return 64.4%, Sharpe 1.37, max DD 29.8%. 30-Delta straddle: avg weekly return 9.7%, total return 93.4%, Sharpe 1.13, max DD ~30%. 30-Delta risk reversal: avg weekly return 13.5%, total return 22.2%, Sharpe 0.69, max DD 26.9%. ATM straddle: Sharpe ~1.14. All structures show persistent positive return — the variance premium is robust. Risk reversals have lower Sharpe despite higher per-trade return — higher variance from directional component.
