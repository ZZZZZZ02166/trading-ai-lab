# Setting Performance Goals: Success, Respectability, Failure

**Type:** strategy_idea
**Source:** Volatility Trading, + Website Wiley (2013) — pp. 176-176

## Summary

Sinclair recommends pre-defining three goal levels for any strategy: (1) Success: e.g., Sharpe > 1.5, annual return > 20% — the level that justifies continued trading and risk-taking; (2) Respectability: e.g., Sharpe 0.8-1.5, 10-20% return — acceptable but not exceptional; (3) Failure: Sharpe < 0.5, drawdown > 30% — stop trading and re-evaluate. Set these thresholds before trading, not after seeing results. Avoid adjusting thresholds post-hoc. Important: require a minimum number of trades (100+) before evaluating with confidence — a strategy appearing in the 'failure' zone after 20 trades may simply be experiencing normal variance.
