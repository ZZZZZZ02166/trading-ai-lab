# Sharpe, Sortino, and Omega Ratios

**Type:** definition
**Source:** Volatility Trading, + Website Wiley (2013) — pp. 176-176

## Summary

Sharpe Ratio = (R_p − R_f) / σ_p — return above risk-free per unit of total volatility. Benchmark: Sharpe > 1 is respectable; > 2 is excellent for a vol strategy. Weakness: treats upside and downside volatility identically. Sortino Ratio = (R_p − MAR) / σ_downside — uses only downside deviation. Better for skewed return distributions (vol selling has negative skew). Omega Ratio = [∫(1−F(r))dr] / [∫F(r)dr] (above/below threshold L). Ω > 1 means expected gain exceeds expected loss. Advantage over Sharpe: uses the full return distribution — not just mean and variance. More appropriate for strategies with non-normal returns like volatility selling.
