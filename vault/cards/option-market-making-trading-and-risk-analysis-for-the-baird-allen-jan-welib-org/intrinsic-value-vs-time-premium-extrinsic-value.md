# Intrinsic Value vs Time Premium (Extrinsic Value)

**Type:** definition
**Source:** Option Market Making — pp. 21–22

## Summary

Intrinsic value is the immediate exercise value of an option — for a call, the amount by which the asset price exceeds the strike; for a put, the amount by which the strike exceeds the asset price. Options without intrinsic value are out-of-the-money. The value above intrinsic value is the time premium (extrinsic value), which reflects the probability that the option will move further in-the-money before expiration. At expiration, all time premium vanishes.
