# Op-Eval Pro: Single Option Calculator

**Type:** concept
**Source:** My Learnings   Trading Options As A Professional — pp. 57-59

## Summary

The book uses Op-Eval Pro software to illustrate option pricing. The Single Option Calculator inputs: stock price, strike, volatility, interest rate, dividends, days to ex-div, days to expiry. Outputs: theoretical call and put values, delta, gamma, vega, 7-theta, rho. Example: stock 58, strike 60, vol 35%, int 4% → call value 46.73, delta 0.93, vega 0.40.
