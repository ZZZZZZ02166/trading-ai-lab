# Intrinsic Value vs. Time Value

**Type:** concept
**Source:** My Learnings   Trading Options As A Professional — pp. 32-34

## Summary

Option price = intrinsic value + time value. Intrinsic value is the in-the-money amount (max 0 vs. stock-strike difference). Time value is the remainder. Deep-ITM options trade near intrinsic value with minimal time premium; a 55 Call with stock at 67 has intrinsic value of 12 and zero time value — it 'trades at parity.' OTM options consist entirely of time value.
