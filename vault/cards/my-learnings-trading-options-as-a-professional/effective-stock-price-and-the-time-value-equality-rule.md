# Effective Stock Price and the Time-Value Equality Rule

**Type:** principle
**Source:** My Learnings   Trading Options As A Professional — pp. 173-174

## Summary

When interest rates are zero and there are no dividends, the time value of a call equals the time value of a put with the same strike. Example: stock at $97, strike $100 — Call value $3 (all time value), Put value $5.50 ($3 intrinsic + $2.50 time value — wait, put time value = $2.50 = call time value). In practice, with non-zero rates: call time value > put time value by the interest on the strike. Knowing this helps identify when one leg is relatively mispriced.
