# Theta: Daily Time Decay

**Type:** definition
**Source:** Trading Option Greeks 2e — pp. 54-55

## Summary

Theta = change in option value per unit of time. Long options: negative theta (lose value daily). Short options: positive theta (gain value daily). ATM options have the highest absolute theta. Theta accelerates as expiration approaches; it is not linear but steepens in the final weeks.
