# Double Calendar: Both-Sided Theta + Vega Collection

**Type:** strategy_idea
**Source:** Trading Option Greeks 2e — pp. 235-237

## Summary

Double calendar = long call calendar + long put calendar at different strikes, bracketing the current price. Benefits from stock staying in a range (theta) while having more strike options than a single calendar. Also a vol play: buying the double calendar profits from rising IV (long vega).
