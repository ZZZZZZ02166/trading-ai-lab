# Vertical Spread: Same Type, Same Expiry, Different Strikes

**Type:** definition
**Source:** Trading Option Greeks 2e — pp. 173-175

## Summary

Buy and sell options of the same type (both calls or both puts), same underlying, same expiration, different strikes. Defines both maximum profit and maximum loss. Reduces cost and vega/gamma exposure vs. outright options. The foundation of most retail spread strategies.
