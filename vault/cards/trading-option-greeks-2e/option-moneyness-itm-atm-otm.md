# Option Moneyness: ITM, ATM, OTM

**Type:** definition
**Source:** Trading Option Greeks 2e — pp. 22-23

## Summary

For calls: ITM = stock > strike; ATM = stock ≈ strike; OTM = stock < strike. For puts the relationship reverses: ITM = stock < strike; OTM = stock > strike. Intrinsic value exists only for ITM options. All premium above intrinsic value is time value (extrinsic value).
