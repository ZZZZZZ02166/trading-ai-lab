# Dividend Surprise: Impact on Long Calls

**Type:** caution
**Source:** Trading Option Greeks 2e — pp. 170-170

## Summary

If XYZ raises its quarterly dividend from $0.10 to $0.40 unexpectedly, the stock price drops $0.30 more than expected on ex-date. A long ITM call valued at $1.65 using the 'wrong' dividend becomes $1.35 using the 'right' dividend—a $0.30 loss from incorrect dividend input alone.
