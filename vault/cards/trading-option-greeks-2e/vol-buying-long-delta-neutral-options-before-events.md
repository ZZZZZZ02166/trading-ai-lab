# Vol Buying: Long Delta-Neutral Options Before Events

**Type:** strategy_idea
**Source:** Trading Option Greeks 2e — pp. 255-257

## Summary

Buy delta-neutral options when IV is historically low, ahead of anticipated vol expansion. Profit from rising IV (vega) and/or gamma scalping on large moves. Risk: if no event materializes and IV stays low, theta erodes the position.
