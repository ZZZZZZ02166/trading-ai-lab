# Volatility Buying vs. Selling: Same Underlying, Opposite Views

**Type:** concept
**Source:** Trading Option Greeks 2e — pp. 257-259

## Summary

Bobby Buyer's approach (ch.12): buys delta-neutral options before an earnings event expecting a vol crush after a big move. Susie Seller's approach: sells delta-neutral options expecting the IV crush to profit more than any gamma scalps cost. Same stock, same setup, opposite vol views.
