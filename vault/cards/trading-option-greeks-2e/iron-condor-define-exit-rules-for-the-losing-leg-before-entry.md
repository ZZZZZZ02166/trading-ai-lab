# Iron Condor: Define Exit Rules for the Losing Leg Before Entry

**Type:** caution
**Source:** Trading Option Greeks 2e — pp. 213-214

## Summary

When one leg is threatened by a directional move: options are close the spread, close only the threatened side, or roll to a further strike. No automatic action is always correct—requires judgment on continued directional risk. Define your max loss threshold before entering the trade.
