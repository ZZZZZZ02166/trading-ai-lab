# Short Straddle: Define Max Loss Before Entry

**Type:** caution
**Source:** Trading Option Greeks 2e — pp. 301-302

## Summary

Negative gamma compounds losses rapidly as the underlying moves. Critical discipline: define your max loss threshold before entry (e.g., close if position reaches 1.5× credit collected). Never average into a losing short straddle. The unlimited risk profile requires pre-defined exit rules.
