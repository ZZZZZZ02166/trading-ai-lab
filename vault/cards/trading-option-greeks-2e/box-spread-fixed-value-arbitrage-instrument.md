# Box Spread: Fixed-Value Arbitrage Instrument

**Type:** definition
**Source:** Trading Option Greeks 2e — pp. 144-146

## Summary

Box = bull call spread + bear put spread (same strikes, same expiration). Value at expiration = upper strike − lower strike (always). Present value = (upper − lower) − interest. If the box trades below fair value, buying it locks in a riskless interest-rate return.
