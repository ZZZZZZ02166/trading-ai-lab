# Gamma-Theta Breakeven: Realized vs. Implied Vol

**Type:** principle
**Source:** Trading Option Greeks 2e — pp. 266-267

## Summary

For gamma scalping to be profitable, the stock's realized daily moves must exceed what was priced into the options. Breakeven daily move ≈ option's implied 1-day σ. If realized vol > implied: scalps exceed theta. If realized < implied: theta destroys more value than scalps recover.
