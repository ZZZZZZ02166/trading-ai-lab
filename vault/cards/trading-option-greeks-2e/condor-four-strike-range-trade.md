# Condor: Four-Strike Range Trade

**Type:** definition
**Source:** Trading Option Greeks 2e — pp. 194-196

## Summary

Short condor: sell inner vertical spread, buy outer vertical spread for protection. Net credit. Maximum profit if stock stays inside the inner strikes at expiration. The width between inner and outer strikes defines the max-loss zone.
