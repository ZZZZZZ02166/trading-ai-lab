# Put-Call Parity Enables All Synthetic Positions

**Type:** principle
**Source:** Trading Option Greeks 2e — pp. 128-129

## Summary

Rearranging put-call parity: long call = long put + long stock; long put = long call + short stock. Any option position can be replicated with the other option type + stock. This equivalence enables synthetics, conversions, reversals, and arbitrage.
