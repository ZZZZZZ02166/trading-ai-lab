# Synthetic Long Call = Long Put + Long Stock

**Type:** definition
**Source:** Trading Option Greeks 2e — pp. 131-132

## Summary

Equivalent to buying a call per put-call parity. Used when the actual call is overpriced, unavailable, or has worse bid-ask spreads. The put + stock combination delivers the same payoff at expiration.
