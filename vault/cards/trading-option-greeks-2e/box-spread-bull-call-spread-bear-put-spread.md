# Box Spread = Bull Call Spread + Bear Put Spread

**Type:** definition
**Source:** Trading Option Greeks 2e — pp. 193-194

## Summary

A box = bull call spread + bear put spread (same strikes, same expiration) = fixed-value instrument worth exactly (upper − lower) strike at expiration. Professionals use boxes to lock in interest rates or arbitrage mispriced combinations of spreads.
