# Price-Weighted Index: Component Impact via Divisor

**Type:** mechanism
**Source:** Option Volatility and Pricing — pp. 3153-3158

## Summary

For a price-weighted index, change in index per $1 move in any component = $1 / divisor. Example: divisor = 1.50, then each $1 change in any component stock changes the index by $0.667, regardless of that stock's price. Higher-priced components dominate index moves in price-weighted indexes (unlike cap-weighted indexes where higher market-cap stocks dominate). Index option delta calculations must account for component weighting — the delta of an index option vs. a specific component stock is scaled by the component's weight in the index.
