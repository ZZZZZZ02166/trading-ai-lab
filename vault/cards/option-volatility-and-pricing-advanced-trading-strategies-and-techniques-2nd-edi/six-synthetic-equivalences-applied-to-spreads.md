# Six Synthetic Equivalences Applied to Spreads

**Type:** mechanism
**Source:** Option Volatility and Pricing — pp. 1865-1874

## Summary

Every option spread can be rewritten using synthetics. A bull call spread (+lower call / −upper call) = −(bear put spread) = long call spread at same strikes. A long straddle (long call + long put) = long underlying + 2 long puts = short underlying + 2 long calls. A long butterfly (+lower / −2 middle / +upper) can be expressed as a long call spread + short call spread. Understanding these equivalences lets traders: (1) find cheaper construction paths using skew; (2) verify P/L calculations; (3) identify equivalent positions for margin purposes.
