# Footprints Need Venue-Level Executed Volume

**Source** [PDF pp. 17–19](../../../books/Order-Flow-Trading-Setups-1.pdf#page=17)

## Summary

Centralized futures data lets the analyst observe executed size by price and side for that contract. Spot FX is decentralized, so a feed from one broker gives only a partial view of spot activity. Dale uses currency futures for analysis and maps the levels separately when executing in spot.
