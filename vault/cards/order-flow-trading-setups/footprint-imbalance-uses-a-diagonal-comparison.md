# Footprint Imbalance Uses a Diagonal Comparison

**Source** [PDF pp. 36–37](../../../books/Order-Flow-Trading-Setups-1.pdf#page=36)

## Summary

Dale's default imbalance compares executions on one side with the opposing volume at the neighboring price and highlights ratios of 3 to 1 or higher. The diagonal convention differs from whether one side is larger within a single row. The software ratio is configurable.
