# A Footprint Node Is Its Busiest Price Row

**Source** [PDF pp. 26–27](../../../books/Order-Flow-Trading-Setups-1.pdf#page=26)

## Summary

Dale defines a bar's high-volume node by the largest combined bid and ask volume at a single price. This is a local, per-bar reference. A different time window can produce a different node.
