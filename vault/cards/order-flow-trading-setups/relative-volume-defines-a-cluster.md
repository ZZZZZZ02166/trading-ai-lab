# Relative Volume Defines a Cluster

**Source** [PDF pp. 34–35](../../../books/Order-Flow-Trading-Setups-1.pdf#page=34)

## Summary

Dale's footprint shades rows based on executed size so unusually heavy areas stand out from nearby prices. A cluster is a band of relatively heavy trading. Interpretation depends on where the cluster forms and how price subsequently leaves it.
