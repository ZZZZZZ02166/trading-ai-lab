# Cumulative Delta Adds Signed Execution Over Time

**Source** [PDF pp. 41–43](../../../books/Order-Flow-Trading-Setups-1.pdf#page=41)

## Summary

Cumulative delta runs a sum of bar delta from the session start. Price and the running flow total can be shown on matching time axes to compare their direction. A different session reset changes the displayed series.
