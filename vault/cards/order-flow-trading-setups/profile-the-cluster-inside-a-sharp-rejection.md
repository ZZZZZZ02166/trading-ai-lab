# Profile the Cluster Inside a Sharp Rejection

**Source** [PDF pp. 51–54](../../../books/Order-Flow-Trading-Setups-1.pdf#page=51)

## Summary

Look for a fast move that reverses decisively, then locate relatively heavy trading inside the rejection. Track the band after price clearly leaves it and test the first return in the direction of rejection. The move can span more than one candle.
