# Trade Stacked Imbalance Retests With Directional Context

**Source** [PDF pp. 65–70](../../../books/Order-Flow-Trading-Setups-1.pdf#page=65)

## Summary

A stack during a one-way move defines a candidate band. Dale waits for price to move away before it comes back and uses only the first test in this setup. A buying stack approached from above is considered possible support, and the mirrored case possible resistance.
