# Path Dependency of Returns: Why Investors Pay More Than Fair Value for Options

**Type:** concept
**Source:** Positional Option Trading (Wiley Trading) — pp. 77–80

## Summary

Investors care not just about terminal wealth but about the path of returns. Options provide insurance against path-dependent disasters (drawdowns below a threshold), not just final-period outcomes. A portfolio that ends at the same value but took a large drawdown during the period is less preferred even if the final value is identical. This path-dependency is a rational reason to pay above theoretically fair value for downside protection, which contributes to the put variance premium.
