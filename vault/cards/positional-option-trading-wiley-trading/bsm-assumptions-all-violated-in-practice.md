# BSM assumptions all violated in practice

**Type:** caution
**Source:** Positional Option Trading (Wiley Trading) — pp. 31–33

## Summary

BSM assumes: constant volatility, continuous trading, no transaction costs, normally distributed returns, single risk-free rate, unlimited short selling. All are violated. The volatility smile shows non-constant vol; fat tails show non-normality; transaction costs are real; trading is discrete. Despite this, BSM remains useful as a shared measurement standard because everyone uses it to convert prices to IV — its value is as a common language, not as truth.
