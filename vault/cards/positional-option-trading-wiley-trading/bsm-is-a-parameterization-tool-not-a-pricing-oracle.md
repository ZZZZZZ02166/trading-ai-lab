# BSM Is a Parameterization Tool, Not a Pricing Oracle

**Type:** principle
**Source:** Positional Option Trading (Wiley Trading) — pp. 25–26

## Summary

The Black-Scholes-Merton model should not be seen as a formula that tells you what an option is worth. Instead, the market prices options via supply and demand, and BSM converts those market prices into a single parameter: implied volatility. All analysis and forecasting is then done in IV space, not price space. The model is used as a measuring stick, not a valuation engine.
