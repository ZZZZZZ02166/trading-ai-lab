# Option return moments: inherent positive skew of long options

**Type:** concept
**Source:** Positional Option Trading (Wiley Trading) — pp. 156–158

## Summary

Long call options have positively skewed return distributions independent of any directional forecast: maximum loss is limited to premium paid, while upside is theoretically unlimited. Most expire worthless (frequent small losses) but occasional large winners. This positive skewness makes long options attractive even at BSM fair value for speculators who prefer positive-skew instruments. Short options have the opposite skewness — frequent small wins but potential for large losses.
