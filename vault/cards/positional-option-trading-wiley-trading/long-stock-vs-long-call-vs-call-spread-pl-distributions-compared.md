# Long stock vs long call vs call spread: P/L distributions compared

**Type:** volatility_insight
**Source:** Positional Option Trading (Wiley Trading) — pp. 164–166

## Summary

For $100 stock, μ=20%, σ=30%, zero rates: Long stock (Fig 8.1, Table 8.1): Avg $2,640, SD $3,736, Skew 1.12, Profitable 75%. Long ATM call (Fig 8.2, Table 8.2): Avg $1,516, SD $3,198, Skew 1.66, Profitable (lower). ATM/20-delta call spread (Fig 8.3, Table 8.3): Avg $819, SD $1,502, Skew 0.01, Profitable 58%. Lower average for call spread but much lower SD — the spread caps both win and loss. Long call has higher skew (more lottery-like) than stock at lower average return. Structure selection depends on: size of directional forecast confidence, skew preference, and whether variance premium is present (if IV < expected realized, long calls have extra edge).
