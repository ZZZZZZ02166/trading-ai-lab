# The Sinclair Framework: Variance Premium First, Direction Second

**Type:** principle
**Source:** Positional Option Trading (Wiley Trading) — pp. 226–227

## Summary

Positional option trading is primarily about capturing the variance premium (IV > realized vol) while secondarily incorporating directional views. The hierarchy: (1) confirm the variance premium exists for this underlying at this time; (2) check volatility skew for additional structural edge; (3) add directional overlay using subjective pricing (Boness model) if forecast exists; (4) size using Kelly criterion adjusted for negative skew and parameter uncertainty. Every step has a specific analytical tool — the framework is quantitative throughout.
