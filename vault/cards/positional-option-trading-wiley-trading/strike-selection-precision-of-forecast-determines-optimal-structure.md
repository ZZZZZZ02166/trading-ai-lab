# Strike selection: precision of forecast determines optimal structure

**Type:** principle
**Source:** Positional Option Trading (Wiley Trading) — pp. 149–150

## Summary

Table 7.1: Options on a $100 stock. If stock goes to $120: 95-strike → $187 profit, 100-strike → $257, 105-strike → $369, 110-strike → $567. But if stock only goes to $106: 95-strike → $26, 100-strike → $7, 105-strike → −$68, 110-strike → −$100. A correct directional call on the wrong strike can produce a loss. The higher the confidence in the magnitude of the move, the more aggressive the strike selection. Uncertainty about magnitude favors ATM strikes; high-conviction big moves favor OTM strikes.
