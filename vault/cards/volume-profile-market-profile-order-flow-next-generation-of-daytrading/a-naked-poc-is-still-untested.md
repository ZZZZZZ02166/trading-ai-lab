# A Naked POC Is Still Untested

**Source** [PDF pp. 23–26](../../../books/Volume%20Profile%20%26%20Market%20Profile%20Order%20Flow%20for%20Next%20Gen%20Daytrading.pdf#page=23)

## Summary

Forthmann calls a prior control price that has not yet been revisited a naked POC. Price can later return to the level during a different auction. The actual reaction can be assessed with current profile and footprint context.
