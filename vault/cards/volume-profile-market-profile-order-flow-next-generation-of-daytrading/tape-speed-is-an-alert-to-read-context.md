# Tape Speed Is an Alert to Read Context

**Source** [PDF pp. 67–70](../../../books/Volume%20Profile%20%26%20Market%20Profile%20Order%20Flow%20for%20Next%20Gen%20Daytrading.pdf#page=67)

## Summary

The book uses large-print and speed-of-tape displays to call attention to an acceleration near a swing, reference zone, or stop run. The display alerts the trader to inspect the next price reaction. A burst can mark exhaustion or the start of a directional move.
