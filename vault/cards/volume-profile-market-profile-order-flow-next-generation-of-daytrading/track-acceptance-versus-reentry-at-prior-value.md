# Track Acceptance Versus Reentry at Prior Value

**Source** [PDF pp. 28–30](../../../books/Volume%20Profile%20%26%20Market%20Profile%20Order%20Flow%20for%20Next%20Gen%20Daytrading.pdf#page=28)

## Summary

The location of the open is only the first observation. Forthmann distinguishes an outside open that sustains activity beyond value from one that quickly returns inside. In balance, the prior control price can be an intermediate rotation reference.
