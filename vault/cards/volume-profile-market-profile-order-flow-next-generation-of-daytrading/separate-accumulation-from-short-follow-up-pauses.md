# Separate Accumulation From Short Follow-Up Pauses

**Source** [PDF pp. 55–57](../../../books/Volume%20Profile%20%26%20Market%20Profile%20Order%20Flow%20for%20Next%20Gen%20Daytrading.pdf#page=55)

## Summary

Forthmann draws a flexible profile over an established rotation and watches order flow if a planned reference is nearby. He distinguishes this longer formation from a shorter pause after directional initiative has already appeared. The two pictures imply different stages of an auction.
