# Volume Point of Control Is a Price Mode

**Source** [PDF p. 22](../../../books/Volume%20Profile%20%26%20Market%20Profile%20Order%20Flow%20for%20Next%20Gen%20Daytrading.pdf#page=22)

## Summary

The VPOC is the price with the highest executed volume in the selected profile. Ordinary time-based volume shows how much traded in each time bar. A VPOC and time-based POC can therefore represent different prices in the same auction.
