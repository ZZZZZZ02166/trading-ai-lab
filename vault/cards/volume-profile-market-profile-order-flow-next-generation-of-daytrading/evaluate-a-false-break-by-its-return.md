# Evaluate a False Break by Its Return

**Source** [PDF pp. 166–177](../../../books/Volume%20Profile%20%26%20Market%20Profile%20Order%20Flow%20for%20Next%20Gen%20Daytrading.pdf#page=166)

## Summary

Forthmann describes popular breakouts and reversal formations that fail, leaving traders positioned in the wrong direction. Confirmation comes from rejection, reentry, and a subsequent attempt in the opposite direction. The recognizable formation helps define where a test occurred.
