# Developing POC Migration Tracks Moving Acceptance

**Source** [PDF pp. 45–50](../../../books/Volume%20Profile%20%26%20Market%20Profile%20Order%20Flow%20for%20Next%20Gen%20Daytrading.pdf#page=45)

## Summary

When new trades build sufficient size at another price, the developing volume POC can migrate. Forthmann reads sustained migration in the context of an existing move and fresh initiative. He gives less weight to an isolated shift inside an established range.
