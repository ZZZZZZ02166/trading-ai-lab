# Value Area Contains About Seventy Percent

**Source** [PDF pp. 28–30](../../../books/Volume%20Profile%20%26%20Market%20Profile%20Order%20Flow%20for%20Next%20Gen%20Daytrading.pdf#page=28)

## Summary

Forthmann uses the approximately 70 percent of selected activity bracketed by value area high and value area low. The reference depends on the instrument, interval, and whether the distribution is volume or time based. It provides a way to compare the current open with prior acceptance.
