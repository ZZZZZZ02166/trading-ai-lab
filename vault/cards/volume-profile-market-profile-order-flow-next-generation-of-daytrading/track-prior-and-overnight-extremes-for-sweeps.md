# Track Prior and Overnight Extremes for Sweeps

**Source** [PDF pp. 178–193](../../../books/Volume%20Profile%20%26%20Market%20Profile%20Order%20Flow%20for%20Next%20Gen%20Daytrading.pdf#page=178)

## Summary

The book shows squeezes and prior-day or non-institutional highs and lows getting taken during the main session. The useful observation is how price responds after the extreme is reached, with profile and order flow supplying context. A sweep by itself only identifies the path through the level.
