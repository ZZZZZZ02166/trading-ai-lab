# Main-Session Activity Shapes the Intraday Context

**Source** [PDF pp. 14–18](../../../books/Volume%20Profile%20%26%20Market%20Profile%20Order%20Flow%20for%20Next%20Gen%20Daytrading.pdf#page=14)

## Summary

The book distinguishes participants by horizon and purpose, including hedgers, longer-horizon traders, and day traders. Their activity varies by instrument, release schedule, and primary session. Forthmann treats a single participant label as an interpretation of observed behavior.
