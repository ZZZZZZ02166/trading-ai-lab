# Treat Value-Area Traversal Rates as Historical Claims

**Source** [PDF p. 30](../../../books/Volume%20Profile%20%26%20Market%20Profile%20Order%20Flow%20for%20Next%20Gen%20Daytrading.pdf#page=30)

## Summary

The book mentions an older 80 percent rule for traversing prior value and qualifies its use in current markets. A reproducible test needs explicit definitions for the open, the entry back into value, target touch and observation horizon. A quoted historical heuristic is only a hypothesis for the repo.
