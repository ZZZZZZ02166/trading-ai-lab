# Use Profile Tails to Frame False Breaks

**Source** [PDF pp. 113–117](../../../books/Volume%20Profile%20%26%20Market%20Profile%20Order%20Flow%20for%20Next%20Gen%20Daytrading.pdf#page=113)

## Summary

The crude and E-mini examples establish a short opening range, show a break that fails, then use lower-timeframe footprints to assess the response. Existing single-print tails and value structure give the probe a defined location. A subsequent stack is interpreted in the context of that sequence.
