# DOM Displays Resting Depth at Each Price

**Source** [PDF pp. 64–66](../../../books/Volume%20Profile%20%26%20Market%20Profile%20Order%20Flow%20for%20Next%20Gen%20Daytrading.pdf#page=64)

## Summary

The DOM shows current resting limit orders around the market. Aggressive trades can consume liquidity at the best bid or ask, but resting quotes can change or disappear. Forthmann uses executed flow and price response alongside displayed depth.
