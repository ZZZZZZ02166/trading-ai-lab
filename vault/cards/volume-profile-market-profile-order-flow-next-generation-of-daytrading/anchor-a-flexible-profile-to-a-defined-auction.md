# Anchor a Flexible Profile to a Defined Auction

**Source** [PDF pp. 38–44](../../../books/Volume%20Profile%20%26%20Market%20Profile%20Order%20Flow%20for%20Next%20Gen%20Daytrading.pdf#page=38)

## Summary

Flexible profiles can cover a specific trend, rotation, or multi-day range. The start and end must correspond to a recognizable event or trade window. Using the same range for TPO and volume makes differences in acceptance easier to interpret.
