# A Profile Bounce Can Start Before the Line

**Source** [PDF pp. 52–54](../../../books/Volume%20Profile%20%26%20Market%20Profile%20Order%20Flow%20for%20Next%20Gen%20Daytrading.pdf#page=52)

## Summary

Forthmann treats strong volume and thin-profile transitions as zones. A retest may turn ahead of the original activity, react inside the band, or go through it. He uses the current response to distinguish these possibilities.
