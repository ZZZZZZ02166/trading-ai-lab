# An Opening Drive Depends on the Prior Auction

**Source** [PDF pp. 108–112](../../../books/Volume%20Profile%20%26%20Market%20Profile%20Order%20Flow%20for%20Next%20Gen%20Daytrading.pdf#page=108)

## Summary

Forthmann distinguishes directional opening initiative from a test or rotation. An early push following consolidation can carry a different meaning from a push after several already extended sessions. Earlier tails, value and the new auction provide reference points.
